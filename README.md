# svgedit

静的 HTML だけで動作する SVG エディタ。ビルド不要・依存ライブラリなし。

**▶ ブラウザで開く: https://yugo-yamamoto.github.io/svgedit/**

## 機能

### 描画
- **長方形** — 塗り / 線色 / 線幅 / 角丸 / 線種、Shift で正方形、8 ハンドルでリサイズ
- **直線** — Shift で 45° スナップ、両端点をハンドルで編集
- **テキスト** — 複数行対応

### テキストの詳細指定
- フォント / サイズ / 行間 / 太字 / 斜体 / 揃え
- **長体・平体** — 横比率 20〜200%（アンカー基準の `scale(sx,1)`）
- **カーニング** — `letter-spacing` −30〜+60px
- **縁取り（外側取り）** — `paint-order="stroke fill"` で塗りを縁の上に重ねる。指定値がそのまま外側にはみ出す実寸になるよう `stroke-width` を 2 倍で適用
- 文字色と縁取り色を個別指定

### 入出力
- **SVG 保存** — 選択枠やグリッドを除外して書き出し
- **PNG / JPEG 保存** — 出力ピクセル数を指定可能（縦横比固定、×1〜×4 プリセット、JPEG 品質）
- **SVG 読み込み** — viewBox・背景・テキスト属性を復元して再編集できる
- **クリップボードから貼り付け（Ctrl+V）** — `image/svg+xml`・SVG ファイル・SVG ソースのテキスト・HTML 内の `<svg>` をベクターのまま貼り付け。id の衝突回避、`<style>` の style 属性への展開、スクリプト除去を行う。SVG がなければ PNG などの画像として貼り付け
- **SVG としてコピー / 切り取り（Ctrl+C / Ctrl+X）** — 選択中の図形を単体の SVG としてクリップボードへ。本エディタに貼り戻すと元の図形として編集できる
- **画像** — 拡縮・トリミング

### フォント
- **OS フォントの実在判定** — キャンバス幅の実測で判定し、未インストールの選択肢はグレーアウト（`document.fonts.check()` はフォールバックを `true` と返す実装があるため使用しない）
- Windows / macOS・iOS / Android / 欧文 / 総称 を OS 別のグループに整理
- **Web フォントの動的取得**（Google Fonts, OFL 11 書体）
  - プレビューは `<link>` 注入。`unicode-range` により必要な字形だけが読み込まれる
  - 書き出しは `text=` サブセットを base64 化し `@font-face` として SVG に埋め込むため、他の端末でも同じ字形で表示される
  - `<img>` 経由のラスタライズは外部リソースを読まないため、PNG / JPEG は常に埋め込む
  - 取得に失敗した場合はログに記録して OS フォントで継続

### 自動保存
- 編集内容とパネル設定を **localStorage に自動保存**し、リロードや次回アクセス時に復元する
- 編集のたびにデバウンス保存し、タブを閉じる直前とバックグラウンド移行時にも保存する
- 復元時は使用中の Web フォントを取り直し、要素 id の連番を引き継いで衝突を防ぐ
- 保存はブラウザ内で完結し、サーバーには送信されない。オフにすると保存済みデータも削除される

### そのほか
- キャンバスサイズ / 背景色 / 透明背景 / グリッド / スナップ / 表示倍率
- undo・redo、複製、重ね順変更、矢印キーでの微調整
- イベントログ表示とクリップボードへのコピー

## ショートカット

| キー | 動作 |
|---|---|
| `V` / `R` / `L` / `T` | 選択 / 長方形 / 直線 / テキスト |
| `Delete` | 削除 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 元に戻す / やり直し |
| `Ctrl+D` | 複製 |
| `Esc` | 選択解除 |
| `Shift` | 正方形・45° に固定 |
| 矢印キー | 1px 移動（`Shift` で 10px） |

## ローカルで動かす

静的ファイルなので任意の HTTP サーバーで動く。

```sh
python3 -m http.server 8080
# http://localhost:8080/ を開く
```

## プライバシー

Web フォントを使ったテキストを書き出すとき、埋め込み用サブセットの取得のために**使用中の文字だけ**が Google Fonts に送信される（重複除去とコードポイント順ソート済み）。送信したくない場合は保存パネルの「フォント埋め込み」を OFF にする。ただし PNG / JPEG は仕様上つねに埋め込む。

Web フォントを使わない場合、外部への通信は一切発生しない。自動保存の保存先はブラウザ内の localStorage で、外部には送信されない（オリジンごとに保存領域は分かれる）。
